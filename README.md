# Customer Behavior Analysis

## Overview
This project is an End-to-End Data Analytics solution developed using Python, MySQL, and Power BI. The objective is to analyze customer purchasing behavior, clean raw data, perform SQL analysis, and create an interactive dashboard for business decision-making.

## Project Architecture

↓
